# Airline Passengers Forecasting 📊

## Project Overview
This project predicts future airline passenger demand using time series forecasting.

## Tech Stack
- Python
- Pandas
- Prophet
- Matplotlib

## Features
- Data preprocessing and cleaning
- Time series forecasting model
- Future prediction of passengers
- Visualization of trends and forecasts
- Model evaluation using MAE and RMSE

## Model Used
Facebook Prophet (Time Series Forecasting)

## Output
- Trend analysis
- Future 2-year forecast
- Accuracy evaluation metrics
